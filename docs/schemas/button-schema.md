# 🖲️ Button Schema

The button schema is used to define the appearance of buttons.

To see how each style looks, check [Discord's documentation](https://discord.com/developers/docs/interactions/message-components#button-object-button-styles).

| **Name**  | **Type** | **Description**     |
|-----------|----------|---------------------|
| **label** | string   | The button's label. |
| **style** | string   | The button's style. One of `"Primary"` (blurple), `"Secondary"` (grey), `"Success"` (green) or `"Danger"` (red). |
| **emoji** | string?  | The button's emoji. |
