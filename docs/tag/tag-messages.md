# 🏷 Tag Messages

You can edit tag messages in the `tags.conf` messages file.

| **Name**       | **Type**                                       | **Used when/for...**                                                                                                                                                                                | **Placeholders**                                                                                                                                       |
|----------------|------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------|
| **notFound**   | [Embed schema](../schemas/embed-schema.md)     | A requested tag wasn't found, eg. via a command.                                                                                                                                                    | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• `%id%`, the ID that was searched.                                                 |
| **notAllowed** | [Embed schema](../schemas/embed-schema.md)     | A member that isn't staff tries to create, edit or delete a tag.                                                                                                                                    | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• [`%error_...`](../placeholder/types/error-placeholder-type.md), for the error.    |
| **command**    | [Command schema](../schemas/command-schema.md) | Creating the main tag command.                                                                                                                                                                      | None.                                                                                                                                                  |
| **noTags**     | [🏷 Tag schema](./tag-config.md#-tag-schema)   | A placeholder tag used when a service doesn't have any tags, eg. for [`%request_tag_...`](../request/request-placeholders.md) on a request without a tag. It's never saved and has an ID of `-1`. | None.                                                                                                                                                  |
| **list**       | [List messages](#-list-messages)               | Messages about listing tags.                                                                                                                                                                        | Varies per message.                                                                                                                                    |
| **info**       | [Info messages](#ℹ-info-messages)             | Messages about displaying tag information.                                                                                                                                                          | Varies per message.                                                                                                                                    |
| **create**     | [Create messages](#-create-messages)           | Messages about creating tags.                                                                                                                                                                       | Varies per message.                                                                                                                                    |
| **update**     | [Update messages](#-update-messages)           | Messages about updating tags.                                                                                                                                                                       | Varies per message.                                                                                                                                    |
| **delete**     | [Delete messages](#-delete-messages)           | Messages about deleting tags.                                                                                                                                                                       | Varies per message.                                                                                                                                    |

## 📃 List messages

The `list` object contains messages about listing tags.

| **Name**    | **Type**                                                                 | **Used when/for...**                                                                                                              | **Placeholders**                                                                                                                                                 |
|-------------|--------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **command** | [Command schema](../schemas/command-schema.md)                           | The list subcommand.                                                                                                              | None.                                                                                                                                                            |
| **embed**   | [Templated embed schema](../schemas/templated-embed-schema.md)           | Listing the tags. The template will be used for every tag.                                                                        | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• Inside the template, [`%tag_...`](./tag-placeholders.md), for the tag being filled.         |
| **select**  | [Select menu schema](../schemas/select-menu-schema.md) with `tag` option | A select menu to pick one of the listed tags. The `tag` option will be used as a template for every tag being inserted as an option. | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• Inside the `tag` option, [`%tag_...`](./tag-placeholders.md), for the tag being filled. |
| **empty**   | string                                                                   | Used as the embed's description and the select menu's placeholder when there are no tags.                                         | • [Global placeholders.](../placeholder/global-placeholders.md), only in the embed.                                                                              |

## ℹ️ Info messages

The `info` object contains messages about displaying tag information.

| **Name**    | **Type**                                                           | **Used when/for...**                 | **Placeholders**                                                                                                     |
|-------------|--------------------------------------------------------------------|--------------------------------------|----------------------------------------------------------------------------------------------------------------------|
| **command** | [Command schema](../schemas/command-schema.md) with a `tag` option | The info subcommand.                 | None.                                                                                                                |
| **embed**   | [Embed schema](../schemas/embed-schema.md)                         | Showing the information of the tag.  | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• [`%tag_...`](./tag-placeholders.md), for the tag. |

## ✨ Create messages

The `create` object contains messages about creating tags.

| **Name**    | **Type**                                                                              | **Used when/for...**                                                      | **Placeholders**                                                                                                                                                                                     |
|-------------|---------------------------------------------------------------------------------------|---------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **command** | [Command schema](../schemas/command-schema.md)                                        | The create subcommand.                                                    | None.                                                                                                                                                                                                |
| **modal**   | [Modal schema](../schemas/modal-schema.md) with `name`, `description` and `color` fields | The modal shown when creating or editing a tag.                           | None.                                                                                                                                                                                                |
| **success** | [Embed schema](../schemas/embed-schema.md)                                            | Informing the user the successful creation of the tag.                    | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• [`%tag_...`](./tag-placeholders.md), for the tag.                                                                               |
| **error**   | [Error embeds schema](../schemas/error-embeds-schema.md)                              | Informing the user and logging about an error while creating the tag.     | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• [`%error_...`](../placeholder/types/error-placeholder-type.md), for the error.                                                  |
| **log**     | [Embed schema](../schemas/embed-schema.md)                                            | Logging the creation in the log channel, if enabled.                      | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• [`%tag_...`](./tag-placeholders.md), for the tag.<br>• [`%update_...`](../placeholder/update-placeholders.md), for the creation. |

## 🗑 Delete messages

The `delete` object contains messages about deleting tags.

| **Name**           | **Type**                                                           | **Used when/for...**                                                      | **Placeholders**                                                                                                                                                                                             |
|--------------------|--------------------------------------------------------------------|---------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **command**        | [Command schema](../schemas/command-schema.md) with a `tag` option | The delete subcommand.                                                    | None.                                                                                                                                                                                                        |
| **confirm**        | [Embed schema](../schemas/embed-schema.md)                         | Asking the user to confirm the deletion.                                  | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• [`%tag_...`](./tag-placeholders.md), for the tag.                                                                                       |
| **success**        | [Embed schema](../schemas/embed-schema.md)                         | Informing the user the successful deletion of the tag.                    | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• [`%tag_...`](./tag-placeholders.md), for the tag.                                                                                       |
| **protectedError** | [Embed schema](../schemas/embed-schema.md)                         | Trying to delete the last remaining tag.                                  | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• [`%tag_...`](./tag-placeholders.md), for the tag.<br>• [`%error_...`](../placeholder/types/error-placeholder-type.md), for the error.   |
| **error**          | [Error embeds schema](../schemas/error-embeds-schema.md)           | Informing the user and logging about an error while deleting the tag.     | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• [`%tag_...`](./tag-placeholders.md), for the tag.<br>• [`%error_...`](../placeholder/types/error-placeholder-type.md), for the error.   |
| **log**            | [Embed schema](../schemas/embed-schema.md)                         | Logging the deletion in the log channel, if enabled.                      | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• [`%tag_...`](./tag-placeholders.md), for the deleted tag.<br>• [`%update_...`](../placeholder/update-placeholders.md), for the deletion. |
