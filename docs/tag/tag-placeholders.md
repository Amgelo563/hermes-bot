# 🏷 Tag Placeholders

The tag placeholders extract information about a specific tag. They start with `%tag_...%`.

| **Option**      | **Description**                                                                                            | **Result example**        |
|-----------------|------------------------------------------------------------------------------------------------------------|---------------------------|
| **id**          | The tag's ID.                                                                                              | 1                         |
| **name**        | The tag's name.                                                                                            | Development               |
| **color**       | The tag's color, exactly as it was entered.                                                              | #5865F2                   |
| **description** | The tag's description.                                                                                     | Programming and scripting |
| **createdAt**   | [Date placeholder type](../placeholder/types/date-placeholder-type.md) that displays the tag's creation date. | Depends on the options.   |
