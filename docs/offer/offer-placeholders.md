# 💹 Offer Placeholders

The offer placeholders extract information about a specific offer. They start with `%offer_...%`.

| **Option**           | **Description**                                                                                                                                                                        | **Result example**                             |
|----------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|------------------------------------------------|
| **id**               | The offer's ID, or `0` while creating the offer.                                                                                                                                       | 1                                              |
| **title**            | The offer's title.                                                                                                                                                                     | Sysadmin services                              |
| **description**      | The offer's description.                                                                                                                                                               | I will administrate your server as a sysadmin. |
| **shortDescription** | The offer's description, sliced at a maximum of 100 characters. Deprecated in favor of the more customizable [`%slice_...` global placeholder](../placeholder/global-placeholders.md). | I will administrate your serv…                 |
| **price**            | The offer's price.                                                                                                                                                                     | 10$                                            |
| **thumbnail**        | The offer's thumbnail.                                                                                                                                                                 | https://...                                    |
| **image**            | The offer's image.                                                                                                                                                                     | https://...                                    |
| **userId**           | The offer's user ID.                                                                                                                                                                   | 235428738748121088                             |
| **createdAt**        | [Date placeholder type](../placeholder/types/date-placeholder-type.md) that displays the offer's first post date.                                                                      | Depends on the options.                        |
| **lastPostedAt**     | [Date placeholder type](../placeholder/types/date-placeholder-type.md) that displays the offer's last post date.                                                                       | Depends on the options.                        |
| **tags**             | [Array placeholder type](../placeholder/types/array-placeholder-type.md) that displays the offer's selected tags.                                                                      | Depends on the options.                        |
| **user**             | [Member placeholder type](../placeholder/types/member-placeholder-type.md) that displays the member that created the offer.                                                            | Depends on the options.                        |
| **channelId**        | The offer's post channel ID.                                                                                                                                                           | 770705035650269204                             |
| **messageId**        | The offer's post message ID. Not accurate while creating the offer.                                                                                                                    | 948179167143415868                             |
| **url**              | An URL to the offer's post message. Not accurate while creating the offer.                                                                                                             | https://discord.com/channels/...               |
