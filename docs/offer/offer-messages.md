# 💹 Offer Messages

You can edit offer messages in the `offer.conf` lang file.

| **Name**          | **Type**                                       | **Used when/for...**                                                           | **Placeholders**                                                                                                             |
|-------------------|------------------------------------------------|--------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------|
| **notFoundError** | [Embed schema](../schemas/embed-schema.md)     | A requested offer wasn't found, eg. via a command. | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• `%id%`, the ID that was searched. |
| **empty**         | string                                         | Used for autocompletion when a user doesn't have offers to autocomplete.       | • [Global placeholders.](../placeholder/global-placeholders.md)                                                              |
| **parentCommand** | [Command schema](../schemas/command-schema.md) | Creating the main offer command, to create offers.                             | None.                                                                                                                        |
| **stickyMessage** | [Embed schema](../schemas/embed-schema.md), or an array of up to 10 of them | A sticky message to send to the offer channel, can be disabled through config. | • [Global placeholders.](../placeholder/global-placeholders.md)                                                              |
| **post**          | [Embed schema](../schemas/embed-schema.md)     | The embed to send to the offer channel when posting one.                       | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• [`%offer_...`](./offer-placeholders.md), for the offer. |
| **info**          | [Info messages](#ℹ-info-messages)              | Messages about displaying offer information.                                   | Varies per message.                                                                                                          |
| **create**        | [Create messages](#-create-messages)           | Messages about creating offers.                                                | Varies per message.                                                                                                          |
| **repost**        | [Repost messages](#-repost-messages)           | Messages about reposting offers.                                               | Varies per message.                                                                                                          |
| **update**        | [Update messages](#-update-messages)           | Messages about updating offers.                                                | Varies per message.                                                                                                          |
| **delete**        | [Delete messages](#-delete-messages)           | Messages about deleting offers.                                                | Varies per message.                                                                                                          |
| **search**        | [Search messages](#-search-messages)           | Messages about searching for offers.                                           | Varies per message.                                                                                                          |

## ℹ️ Info messages

The `info` object contains messages about displaying offer information.

| **Name**    | **Type**                                               | **Used when/for...**                     | **Placeholders**                                                                                                             |
|-------------|--------------------------------------------------------|------------------------------------------|------------------------------------------------------------------------------------------------------------------------------|
| **command** | [Command schema](../schemas/command-schema.md)         | The info subcommand.                      | None.                                                                                                                        |
| **linkButton** | [Link button schema](../schemas/link-button-schema.md) | A link button used to link to the offer. | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• [`%offer_...`](./offer-placeholders.md), for the offer. |

## ✨ Create messages

The `create` object contains messages about creating offers.

| **Name**         | **Type**                                                                  | **Used when/for...**                                                                                                 | **Placeholders**                                                                                                                                                                                                               |
|------------------|---------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **command**      | [Command schema](../schemas/command-schema.md)                            | The create command.                                                                                                  | None.                                                                                                                                                                                                                          |
| **modal**        | [Modal schema](../schemas/modal-schema.md)                                | The modal shown when using the create command.                                                                       | None.                                                                                                                                                                                                                          |
| **tagSelect**    | [Select menu schema](../schemas/select-menu-schema.md) with `tag` option  | Creating the tag select menu. The `tag` option will be used as a template for every tag being inserted as an option. | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• [`%offer_...`](./offer-placeholders.md), for the offer.<br>• Inside the `tag` option, [`%tag_...`](../tag/tag-placeholders.md), for the tag being filled. |
| **previewing**   | [Embed schema](../schemas/embed-schema.md)                                | Informing the user they're watching a preview.                                                                       | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• [`%offer_...`](./offer-placeholders.md), for the offer.                                                                                                   |
| **success**      | [Embed schema](../schemas/embed-schema.md)                                | Informing the user the successful creation of the offer.                                                             | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• [`%offer_...`](./offer-placeholders.md), for the offer.                                                                                                   |
| **error**        | [Error embeds schema](../schemas/error-embeds-schema.md)                  | Informing the user and logging about an error while creating the offer.                                              | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• [`%error_...`](../placeholder/types/error-placeholder-type.md), for the error.                                                                            |
| **requirements** | [Requirement embeds schema](../requirements/requirement-embeds-schema.md) | Reporting non fulfilled requirements while creating an offer.                                                        | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• [`%offer_...`](./offer-placeholders.md), for the offer.                                                                                                   |

## 🔍 Search messages

The `search` object contains messages about searching for offers.

| **Name**      | **Type**                                                       | **Used when/for...**                                                                   | **Placeholders**                                                                                                                                                   |
|---------------|----------------------------------------------------------------|----------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **command**   | [Command schema](../schemas/command-schema.md)                 | The search subcommand.                                                                 | None.                                                                                                                                                              |
| **embed**     | [Templated embed schema](../schemas/templated-embed-schema.md) | Showing the search results. The template will be used for every offer found.         | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• Inside the template, [`%offer_...`](./offer-placeholders.md), for the offer being filled. |
| **noResults** | string                                                         | Used as the `embed`'s description when no offers were found.                        | • [Global placeholders.](../placeholder/global-placeholders.md)                                                                                                    |
| **error**     | [Error embeds schema](../schemas/error-embeds-schema.md)       | Informing the user and logging about an error while searching for offers.            | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• [`%error_...`](../placeholder/types/error-placeholder-type.md), for the error.                |

The search results can be filtered with the `filters` select menus in the
[🌎 General Messages](../configs/general-messages.md).
