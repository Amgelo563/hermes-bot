# 🔥 Error Placeholder Type

The error placeholder type is used to extract information about an unexpected error.

| **Name**    | **Type** | **Used for...**                                                                                                                                                                                                                                                                                                                       |
|-------------|----------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **name**    | string   | The error's name, [extracted from `Error#name`.](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Error/name)                                                                                                                                                                                         |
| **message** | string   | The error's message, [extracted from `Error#message`.](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Error/message)                                                                                                                                                                                |
| **stack**   | string   | The error's stack, [extracted from `Error#stack`.](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Error/stack)                                                                                                                                                                                      |
| **id**      | string   | The error's ID. This is a short string created internally, reused for the user error and log error. Its purpose is for the user to be able to report an error with staff, and for them to identify it in the error channel. It does not get stored anywhere, and it's not guaranteed to be 100% unique forever, but it's good enough. |
