# 💬 Discord Configuration

The `discord.conf` configuration has options for configuring settings on Discord.

| **Name**            | **Type**        | **Description**                                 |
|---------------------|-----------------|-------------------------------------------------|
| **token**           | string          | Your Discord bot token.                         |
| **server**          | string          | The ID of the server where the bot will work.   |
| **staffRoles**      | array of string | The IDs of the roles that are considered staff. |
| **errorLogChannel** | string          | The ID of the error log channel.                |
