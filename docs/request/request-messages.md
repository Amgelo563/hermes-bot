# 💰 Request Messages

You can edit request messages in the `request.conf` messages file.

> [!TIP]
> Most messages on this page support [`%request_...`](./request-placeholders.md) placeholders. These always refer to
> the request being created, shown, updated, reposted or deleted.

| **Name**          | **Type**                                                                   | **Used when/for...**                                                                                                     | **Placeholders**                                                                                                                                        |
|-------------------|----------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------|
| **notFoundError** | [Embed schema](../schemas/embed-schema.md)                                 | A requested request wasn't found, eg. via a command.                                                                     | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• `%id%`, the ID that was searched.                                                  |
| **empty**         | string                                                                     | Used for autocompletion when a user doesn't have requests to autocomplete.                                               | • [Global placeholders.](../placeholder/global-placeholders.md)                                                                                         |
| **parentCommand** | [Command schema](../schemas/command-schema.md)                             | Creating the main request command, to manage requests.                                                                   | None.                                                                                                                                                   |
| **stickyMessage** | [Embed schema](../schemas/embed-schema.md), or an array of up to 10 of them | A sticky message to send to the request channel, can be disabled through config.                                         | • [Global placeholders.](../placeholder/global-placeholders.md)                                                                                         |
| **post**          | [Embed schema](../schemas/embed-schema.md)                                 | The embed to send to the request channel when posting one. Also used in logs to show the old and new versions of a request. | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• [`%request_...`](./request-placeholders.md), for the request.                   |
| **info**          | [Info messages](#ℹ-info-messages)                                         | Messages about displaying request information.                                                                           | Varies per message.                                                                                                                                     |
| **create**        | [Create messages](#-create-messages)                                       | Messages about creating requests.                                                                                        | Varies per message.                                                                                                                                     |
| **repost**        | [Repost messages](#-repost-messages)                                       | Messages about reposting requests.                                                                                       | Varies per message.                                                                                                                                     |
| **update**        | [Update messages](#-update-messages)                                       | Messages about updating requests.                                                                                        | Varies per message.                                                                                                                                     |
| **delete**        | [Delete messages](#-delete-messages)                                       | Messages about deleting requests.                                                                                        | Varies per message.                                                                                                                                     |
| **search**        | [Search messages](#-search-messages)                                       | Messages about searching for requests.                                                                                   | Varies per message.                                                                                                                                     |

## ℹ️ Info messages

The `info` object contains messages about displaying request information.

| **Name**       | **Type**                                                                   | **Used when/for...**                       | **Placeholders**                                                                                                                   |
|----------------|----------------------------------------------------------------------------|--------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------|
| **command**    | [Command schema](../schemas/command-schema.md) with a `request` option     | The info subcommand.                       | None.                                                                                                                              |
| **linkButton** | [Link button schema](../schemas/link-button-schema.md)                     | A link button used to link to the request. | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• [`%request_...`](./request-placeholders.md), for the request. |

## ✨ Create messages

The `create` object contains messages about creating requests.

| **Name**         | **Type**                                                                                    | **Used when/for...**                                                                                                 | **Placeholders**                                                                                                                                                                                                                       |
|------------------|---------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **command**      | [Command schema](../schemas/command-schema.md)                                              | The create command.                                                                                                  | None.                                                                                                                                                                                                                                  |
| **modal**        | [Modal schema](../schemas/modal-schema.md) with `title`, `description` and `budget` fields | The modal shown when using the create command.                                                                       | None.                                                                                                                                                                                                                                  |
| **tagSelect**    | [Select menu schema](../schemas/select-menu-schema.md) with `tag` option                    | Creating the tag select menu. The `tag` option will be used as a template for every tag being inserted as an option. | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• [`%request_...`](./request-placeholders.md), for the request.<br>• Inside the `tag` option, [`%tag_...`](../tag/tag-placeholders.md), for the tag being filled. |
| **previewing**   | [Embed schema](../schemas/embed-schema.md)                                                  | Informing the user they're watching a preview.                                                                       | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• [`%request_...`](./request-placeholders.md), for the request.                                                                                                   |
| **success**      | [Embed schema](../schemas/embed-schema.md)                                                  | Informing the user the successful creation of the request.                                                           | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• [`%request_...`](./request-placeholders.md), for the request.                                                                                                   |
| **error**        | [Error embeds schema](../schemas/error-embeds-schema.md)                                    | Informing the user and logging about an error while creating the request.                                            | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• [`%error_...`](../placeholder/types/error-placeholder-type.md), for the error.                                                                                    |
| **requirements** | [Requirement embeds schema](../requirements/requirement-embeds-schema.md)                   | Reporting non fulfilled requirements while creating a request.                                                       | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• [`%request_...`](./request-placeholders.md), for the request.                                                                                                   |

| **requirements** | [Requirement embeds schema](../requirements/requirement-embeds-schema.md) | Reporting non fulfilled requirements while reposting a request.                                                                                     | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• [`%request_...`](./request-placeholders.md), for the request.                                                     |
| **error**        | [Error embeds schema](../schemas/error-embeds-schema.md)                  | Informing the user and logging about an error while reposting the request.                                                                          | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• [`%request_...`](./request-placeholders.md), for the request.<br>• [`%error_...`](../placeholder/types/error-placeholder-type.md), for the error. |
| **success**      | [Embed schema](../schemas/embed-schema.md)                                | Informing the user the successful repost of the request.                                                                                            | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• [`%request_...`](./request-placeholders.md), for the request.                                                     |

## 🔍 Search messages

The `search` object contains messages about searching for requests.

| **Name**      | **Type**                                                       | **Used when/for...**                                                                   | **Placeholders**                                                                                                                                                   |
|---------------|----------------------------------------------------------------|----------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **command**   | [Command schema](../schemas/command-schema.md)                 | The search subcommand.                                                                 | None.                                                                                                                                                              |
| **embed**     | [Templated embed schema](../schemas/templated-embed-schema.md) | Showing the search results. The template will be used for every request found.         | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• Inside the template, [`%request_...`](./request-placeholders.md), for the request being filled. |
| **noResults** | string                                                         | Used as the `embed`'s description when no requests were found.                        | • [Global placeholders.](../placeholder/global-placeholders.md)                                                                                                    |
| **error**     | [Error embeds schema](../schemas/error-embeds-schema.md)       | Informing the user and logging about an error while searching for requests.            | • [Global placeholders.](../placeholder/global-placeholders.md)<br>• [`%error_...`](../placeholder/types/error-placeholder-type.md), for the error.                |

The search results can be filtered with the `filters` select menus in the
[🌎 General Messages](../configs/general-messages.md).
