# 💰 Request

The request feature allows users to create, manage and search service requests, that is, services they're looking for.

Unlike offers, a request can only include one [🏷 tag](../tag/tag.md).

## 💻 Available commands

All command names, descriptions and options are editable through
the [💰 Request Messages](request-messages.md) file.

In the default configuration they are named:

- `/request` - To create a request.
- `/requests` - The main request management command.
  - `/requests info` - Shows information about a given request.
  - `/requests update` - Updates your requests. Also usable by staff.
  - `/requests delete` - Deletes your requests. Also usable by staff.
  - `/requests repost` - Reposts your requests.
  - `/requests search` - Searches for requests that match given criteria.
